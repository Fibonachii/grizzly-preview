# GRIZZLY — тестовая версия

[Открыть сайт](https://fibonachii.github.io/grizzly-preview/)

Версия для тестирования, поиска ошибок и сбора обратной связи. На всех HTML-страницах установлен `noindex`; перед каждым развёртыванием это проверяется автоматически.

Сайт доступен всем, у кого есть ссылка. `noindex` управляет поисковой индексацией и не является паролем.

Здесь находятся только настройки публикации. Готовый архив сайта передаётся в ручной запуск workflow вместе с SHA-256 из успешной сборки. Временный адрес загрузки скрывается из логов. Доступ к исходному закрытому репозиторию для публикации не требуется.

Workflow проверяет контрольную сумму, обязательные страницы и noindex каждого HTML перед развёртыванием. Обычные изменения исходников не обновляют тестовый сайт автоматически.
